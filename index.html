Front-End Development FAQ

What is HTML?

expand_more

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on the web, using elements like headings, paragraphs, links, and images.

What is CSS?

expand_more

CSS stands for Cascading Style Sheets. It is used to style and visually design HTML elements — controlling colors, fonts, spacing, layout, and more.

What is JavaScript?

expand_more

JavaScript is a programming language that makes web pages interactive. It allows you to respond to user actions, update content dynamically, and communicate with servers.

What is the DOM?

expand_more

The DOM (Document Object Model) is a programming interface that represents the HTML of a page as a tree of objects. JavaScript uses the DOM to read, add, remove, or change elements on the page.

What is React?

expand_more

React is a JavaScript library created by Facebook for building user interfaces. It lets you break the UI into reusable components, making it easier to build and manage large web applications.

What is the difference between localStorage and sessionStorage?

expand_more

Both are Web Storage APIs used to store data in the browser. localStorage keeps the data even after you close the browser. sessionStorage keeps the data only for the current browser tab — it is cleared when the tab is closed.

What is setTimeout()?

expand_more

setTimeout() is a built-in JavaScript function that runs a piece of code once after a specified delay in milliseconds. For example, setTimeout(myFunction, 2000) will call myFunction after 2 seconds.

What is setInterval()?

expand_more

setInterval() is a built-in JavaScript function that runs a piece of code repeatedly, every specified number of milliseconds, until it is stopped using clearInterval().

What is the difference between a normal function and an arrow function?

expand_more

A normal function is written with the function keyword. An arrow function uses a shorter syntax with =>. The key difference is how they handle this — a normal function has its own this, while an arrow function inherits this from the surrounding code.

What is responsive design?

expand_more

Responsive design means building a website so it looks and works well on all screen sizes — from mobile phones to desktops. It is usually achieved using flexible layouts, relative units, and CSS media queries.

What is the difference between Flexbox and CSS Grid?

expand_more

Flexbox works in one direction at a time — either a row or a column. CSS Grid works in two directions at once — rows and columns together. Use Flexbox for simpler one-directional layouts and Grid for more complex, two-dimensional page layouts.

What is Git and how is it different from GitHub?

expand_more

Git is a version control tool that runs on your computer and tracks changes in your code. GitHub is a website that hosts your Git repositories online so you can share and collaborate with others. Git is the tool — GitHub is the platform.
